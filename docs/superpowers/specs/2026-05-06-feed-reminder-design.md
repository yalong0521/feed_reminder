# 喂奶提醒 App 设计规范

## 1. 项目概述

**项目名称：** Feed Reminder（喂奶提醒）
**项目类型：** Flutter 移动应用（平板优先）
**核心功能：** 记录宝宝喂奶时间，通过倒计时+动画+声音提醒提示下一次喂奶时间
**使用场景：** 平板设备长期固定放置，App 长时间前台运行

---

### 4.1 布局结构

```

│         🍼 喂奶提醒                  │  ← 顶部标题
├─────────────────────────────────────┤
│                                     │
│      ┌───────────────────┐          │
│      │                   │          │
│      │    彩虹圆环        │          │  ← 圆形进度动画
│      │    01:25:30       │          │  ← 大号倒计时
│      │                   │          │
│      └───────────────────┘          │
│                                     │
│         已过去: 00:34:30            │  ← 辅助信息
│                                     │
│     ┌─────────────────────┐         │
│     │   🍼 记录喂奶       │         │  ← 主按钮（圆角胶囊）
│     └─────────────────────┘         │
│                                     │
│    上次喂奶: 10:30 AM              │  ← 状态信息
│                                     │
└─────────────────────────────────────┘
```

### 4.2 彩虹圆环动画

- **实现方式：** CustomPainter 绘制圆形进度条
- **渐变：** 6种颜色（A8D8EA → B5EAD7 → FFE5A0 → FFCBA4 → FFB5C2 → A8D8EA）随进度平滑过渡
- **尺寸：** 屏幕宽度的 60%，线宽 20px

### 4.3 倒计时圆环状态

| 状态 | 动画效果 |
|------|----------|
| 正常 | 彩虹渐变圆环随时间平滑填充 |
| 即将提醒（最后10分钟） | 颜色趋近红色 + 轻微呼吸动画 |
| 到点 | 圆环脉冲 + 背景变色 |
| 夜间模式 | 圆环变暗，显示月亮图标 |

### 4.4 主按钮

- **样式：** 胶囊形状，圆角 30px
- **颜色：** 渐变色（粉→橙）
- **点击效果：** 缩放动画 + 涟漪效果
- **文字：** "🍼 记录喂奶"

### 4.5 到点提醒 UI 变化

- 背景渐变至暖色/红色
- 圆环脉冲闪烁动画
- 震动效果（可选，需用户开启）

## 7. 功能逻辑

### 7.1 核心流程

1. **启动 App**
   - 读取上次喂奶时间和间隔设置
   - 计算下次喂奶时间
   - 启动倒计时
   - 屏幕常亮（如设置开启）

2. **记录喂奶**
   - 保存当前时间
   - 清除已过去时间
   - 重置倒计时至间隔时间
   - 重播动画

3. **倒计时运行**
   - 每秒更新显示
   - 更新圆环进度
   - 检测是否到达下次喂奶时间

4. **到点提醒**
   - 检测是否在夜间时间段
   - 如不在夜间：播放声音 + 视觉变化 + 发送通知
   - 如在夜间：仅视觉变化，不播放声音

### 7.2 提醒机制

| 场景 | 声音 | 视觉 | 通知 |
|------|------|------|------|
| 白天到点 | ✅ | ✅ | ✅ |
| 夜间到点 | ❌ | ✅（轻） | ❌ |

### 7.3 数据存储

- **存储方式：** SharedPreferences
- **存储内容：**
  - `lastFeedTime` (int, timestamp)
  - `feedIntervalMinutes` (int)
  - `nightModeEnabled` (bool)
  - `nightStartTime` (String, "HH:mm")
  - `nightEndTime` (String, "HH:mm")
  - `soundEnabled` (bool)
  - `soundLoopEnabled` (bool)
  - `wakelockEnabled` (bool)
  - `feedHistory` (String, JSON array)

## 9. 动画规格

### 9.1 彩虹圆环

- **类型：** CustomPainter + AnimationController
- **时长：** 持续动画（圆环颜色流动）
- **帧率：** 60fps

### 9.2 呼吸动画

- **类型：** ScaleTransition
- **时长：** 1500ms
- **曲线：** easeInOut
- **范围：** 1.0 → 1.05 → 1.0

### 9.3 按钮点击

- **类型：** ScaleTransition
- **时长：** 100ms
- **范围：** 1.0 → 0.95 → 1.0

### 9.4 提醒闪烁

- **类型：** OpacityAnimation
- **时长：** 500ms
- **范围：** 1.0 → 0.7 → 1.0
- **循环：** 持续直到用户交互

## 简短申请说明

奶点记是喂奶记录与提醒工具。提醒时间为“最近一次喂奶时间＋用户设定间隔”，默认间隔为 180 分钟；设置页面支持 1–1440 分钟自定义。没有喂奶记录时不创建任务。每次仅保留下一条单次日历代理提醒，不注册每日或周期重复任务，到点后不会自动生成下一轮任务。新增、删除记录或调整设置时重新计算并撤销旧任务；用户点击停止提醒后撤销本周期提醒。

通知使用固定内容：

- 标题：到设定的喂奶时间了
- 正文：留意宝宝的状态，准备好后记下这一餐。

前台由应用按声音及循环设置播放提示音，并显示通知；进入后台后停止应用内音频，由系统代理处理已安排的到点通知。后台不使用循环播放音频维持运行。关闭声音使用低优先级通知槽，实际声音与展示遵循用户系统通知设置；启用夜间静音且预计到点时间落在该时段时不安排通知。该权限仅服务于用户的喂奶记录及提醒，不用于广告、营销或其他推送。

# 奶点记

一个离线使用的 Flutter 喂奶记录与提醒应用。日光手账以暖纸底色、陶土色和大号衬线数字呈现倒计时，提供协调的深色外观；横屏使用手账侧栏，竖屏使用底部导航，记录与补记集中在计时页下方。同时适配小屏、大字体和平板。记录与设置保存在本机，无需账户。

更新内容与验证记录见 [变更日志](CHANGELOG.md)。

## 使用方式

- **首次使用**：鸿蒙商店版本仅在中国大陆发布，使用华为隐私托管，由系统在首次使用时展示隐私声明并管理同意状态；「设置 → 隐私政策」打开当前托管声明。其他平台显示应用内隐私提示，可离线阅读完整政策，确认并成功保存后才进入应用、恢复提醒和申请通知权限。隐私确认不会清除已有记录或设置。
- **记录喂奶**：从首页滑块左侧向右滑到底并松开，才会保存。点击、短滑或取消手势不会生成记录。保存成功后可在原位撤销，操作窗口为 6 秒；保存失败可重新滑动重试。
- **记录奶量**：在设置中配置默认奶量（0–2000 mL 的整数），首页滑块显示本次将保存的奶量，滑动确认时一并记录。点击滑块旁的奶量入口可临时调整下一餐，使用可横向拖动的刻度或直接输入；两者同步，刻度默认覆盖 0–360 mL，输入更大数值时自动扩展，不将合法整数取整为固定档位。成功记录后恢复默认，取消或保存失败保留原选择。默认值为 0，表示未记录奶量；修改默认值只影响后续新增记录。
- **查看与补记**：记录页按日期展示时间、奶量和相邻喂奶间隔，支持补记、修改时间与奶量及确认删除，每天汇总次数和总奶量。旧记录按 0 mL 保留，可逐条补充实际奶量。倒计时始终以最新一条记录为准，只修改奶量不会重置提醒，补记更早的时间不会重置当前计时；删除全部记录后清空计时。历史不再按条数自动删减，列表按需创建可见条目。
- **查询与统计**：记录页支持查询一天或日期范围并清除筛选。奶量统计支持近 7 天、近 30 天和自选范围（最多 366 天），日柱图每页最多 30 天。总奶量为已填写奶量之和，日均按范围的全部自然日计算；单餐平均仅计算已填写奶量的记录，平均间隔只取范围内相邻记录。0 mL 仍计入次数，并单独提示未记录奶量的次数。
- **数据管理**：「设置 → 数据管理」可备份 JSON、预览并合并恢复、导出带中文表头的 CSV。备份仅含喂奶记录；重复记录跳过，同 ID 冲突保留本机版本，恢复一次性保存。文件最多 10 MiB、50,000 条记录；合并后的完整记录也需能在此限制内再次备份，超限时保留本机数据并提示。普通喂奶记录不受导入上限限制，也不会自动删减。CSV 用于表格阅读，不能恢复。导出文件需要自行保管，删除应用记录不会删除已导出的文件。
- **调整提醒**：设置喂奶间隔（1–1440 分钟）、夜间静音时段、声音及循环播放，可单独试听提醒音。
- **稍后提醒**：到点且尚未停止本次提醒时，可以从确认时起延后 10、20 或 30 分钟。不新增喂奶记录，也不改变默认间隔；重启后保留，夜间静音仍生效。新一餐、修改当前餐时间或间隔后按新的周期计算；只改奶量或补记更早的一餐不会取消延后。
- **鸿蒙桌面卡片**：提供「下次喂奶」（2×1）、「最近一餐」（2×2）和「喂养概览」（4×2）三种独立入口，尺寸按列×行标注。小卡显示下一次提醒的日期、时间或停止状态；方卡显示最近一餐、奶量和下一次提醒；横卡另显示指定日期的次数与奶量汇总。点击摘要打开计时页，点击记录打开应用内确认面板；卡片不直接写记录。保留原概览卡片入口，既有卡片无需因新增尺寸而重新添加。卡片使用本机最近同步的摘要，小卡的更新时间包含在无障碍说明中，不承诺应用关闭时秒级刷新；跨日后旧汇总仍明确标注所属日期。三种尺寸已通过实际 ArkUI 预览检查，2×1 低高度裁切已修复并在真机复核；后台刷新、多卡片更新和完整系统交互仍需专项验收。
- **选择外观**：在「设置 → 屏幕与外观」选择跟随系统、浅色或深色，默认跟随系统，重启后保留选择。Android 手势导航区域透明，页面背景延伸至小白条下方；手势条随主题调整对比色，操作控件保留安全距离。外观与夜间静音分别设置。
- **固定放置**：计时首页有记录时保持屏幕常亮，切页或进入后台会释放。开启防烧屏保护后，闲置约 30 秒进入深色移动时钟；轻触或首次按键仅唤醒。到点提醒会自动退出待机，之后约 30 秒无操作可再次进入，并显示「超时」和超时时长。声音仍按原设置播放，停止本次提醒后也可待机；待机不改变手机的系统亮度。
- **操作触感**：在支持的 Android、iOS 和鸿蒙设备上，主动调整奶量、确认保存和操作错误可伴随短促触感；设置仅在实际改变并保存后反馈。触感仅在前台触发，连续操作会节流，取消、普通导航和程序同步不会普遍触发振动。鸿蒙使用系统触摸振动用途，实际效果受设备与系统策略影响；触感不可用或失败不影响记录保存。Web 和桌面平台不提供此触感。

支持键盘和读屏操作。键盘使用右方向键逐步推进记录滑块，再按回车确认；读屏使用滑块的逐步调整动作。滑块具有轻微按压缩放和跟随进度的暖色渐变，系统减少动态效果时关闭额外缩放与回弹。系统高对比模式下，倒计时使用更厚的字形与更清晰的细节。数字下方的时间轴标出上次喂奶、当前时间和下一次提醒；已过时间变浅，剩余时间保留主题色，跨天时补充日期。到点后显示「超时 · 累计分钟数 · 分钟」，左右标签使用相同字号、字重并等宽占位，数字保持居中，并保留精确到秒的读屏语义。首页和防烧屏模式的倒计时、超时数字共用字号标准，仅在实际空间不足时缩小。超时数字轻微变亮、缩放，左右标签不参与动画，系统减少动态效果时静止显示。时间轴能放下时对照原定与当前时间；真正矮屏隐藏时间轴及时间对照，停止提醒后仍保留超时状态。超时待机只显示居中的超时行和「轻触唤醒」，整组内容持续移动防烧屏。

## 提醒行为与限制

前台显示倒计时，并按设置播放提醒音；循环音频仅在应用前台播放。停止本次提醒的状态会保留到重启后。后台通过系统安排下一次通知，实际投递受设备权限和省电策略影响。

停止状态保存失败时，当前声音仍停止，页面明确显示“重试保存停止状态”；保存成功后才显示已持久化的停止状态并同步桌面卡片。记录首次读取失败时不将其当作空历史，不取消已有系统提醒；可在页面点击“重新读取记录”恢复，无需重启应用。

误操作新增记录后撤销，会恢复旧周期已保存的停止提醒状态。循环声音遇到播放错误时会在前台重试，单次声音正常播完不会自动重播；用户明确停止后，切回前台也不会擅自重新播放。

Android 未授予精确闹钟权限时，会使用系统允许的不精确通知，可在设置页打开通知和准时提醒权限。夜间静音保留应用内视觉提示、关闭前台声音；预定时间位于静音时段时不安排系统通知。夜间开始与结束相同表示不进入静音时段。不精确通知可能因系统延迟跨入静音时段，后台投递时无法再次判断夜间窗口。

Web 和 Windows 支持记录与前台计时，不提供系统定时通知。发布前应在目标真机上验证后台省电限制、长时间锁屏提醒和 iOS 行为。

## 开发与运行

原生鸿蒙使用独立的 Flutter-OH 工具链，本轮使用 Flutter-OH 3.41.10-ohos-1.0.1（Dart 3.11.5）与 DevEco/API 26 完成构建验证。构建、签名和提醒能力说明见 [鸿蒙开发与验证](tool/ohos/README.md)。

使用 Flutter 3.47.4（Dart 3.13.3）和 JDK 17。本轮新增五项功能使用 Flutter 3.41.9（Dart 3.11.5）验证；此前奶量版本另在 Flutter 3.47.2（Dart 3.13.2）复验通过。SDK 安装目录名称不一定等于实际版本，请以 `flutter --version` 为准。当前 Android Gradle 8.14 与 Java 25 不兼容。使用 FVM 时，可在项目根目录执行：

```powershell
fvm use 3.47.4
fvm flutter config --jdk-dir="你的 JDK 17 安装目录"
fvm flutter pub get
fvm flutter run
```

正式入口为 `lib/main.dart`。IDE 和命令行应使用同一套 Flutter SDK。`flutter config --jdk-dir` 是用户级设置，会影响本机其他 Flutter 项目。

本轮使用的 Flutter 3.41.9 在新增插件后可能复用旧 Web 入口缓存。若 `flutter pub get` 后 Web 仍报告文件插件未注册，可只移除 `.dart_tool/flutter_build` 下的 `web_entrypoint.stamp` 与 `web_plugin_registrant.dart` 并重新构建 Web；不必清除其他平台产物。

Apple 工程最低支持 iOS 15、macOS 12，与当前 Flutter SDK 要求一致。
iOS / macOS 已接入 Flutter 的 Swift Package Manager；尚未支持它的通知插件
继续通过 CocoaPods 集成。首次构建请使用 `fvm flutter build ios --simulator`
或 `fvm flutter build macos`，生成插件配置并安装依赖后再从 Xcode 打开对应
`Runner.xcworkspace`。生成的插件包位于 `ephemeral` 目录，无需提交。

Windows 本机测试需要 Visual Studio 的 C++ 工具链：项目将 `win32` 构建钩子配置为本地编译。Android、iOS 和 Web 构建不执行这段 Windows 编译。

## 应用标识

Android、iOS、macOS、鸿蒙和 Linux 的主应用标识统一为 `com.weiyalong.naidianji`，
iOS / macOS 测试目标使用 `com.weiyalong.naidianji.RunnerTests`。
正式签名和商店登记需要与各平台的这个标识匹配。

鸿蒙本轮设备测试使用独立标识 `com.weiyalong.naidianji.dev`，与商店版并存，记录、设置与授权不会自动共享。主应用标识保持不变。原标识的覆盖安装曾因签名不匹配返回 `9568332`，未执行卸载，商店版及其数据保留。

Android 的 Kotlin 包和 namespace 同步使用该标识；Dart 包名 `feed_reminder`
以及内部 MethodChannel 名称不属于安装标识，保持原有值。
Windows 当前是普通 EXE 工程，尚未配置 MSIX 商店身份；Web 使用站点地址识别，
不将移动端包名写入 Web manifest。

从旧示例标识切换后，系统会视为新的应用，旧标识下的本地记录、设置和授权不会自动迁移。
鸿蒙原本已使用此标识，不涉及这次标识迁移。

## 目录职责

- `lib/main.dart`、`lib/app.dart`：启动、依赖装配、主题和页面导航。
- `lib/screens`、`lib/widgets`：自适应页面、等宽倒计时数字与共用交互组件。
- `lib/theme`：明暗主题、字体及 Cupertino 控件样式。
- `lib/providers`：计时状态、设置及提醒协调，支持注入时钟。
- `lib/repositories`、`lib/models`：记录模型、排序及相邻喂奶间隔。
- `lib/services`：本地存储、音频播放及系统通知。
- `test`、`integration_test`：单元、组件和设备集成测试。

## 界面资源与许可

界面以暖纸表面、开放式分组和细分隔线建立层级；不依赖玻璃着色器。Tinos 仅用于倒计时和待机页面的大号时间，使用等宽数字；其余文字使用系统默认字体。倒计时不会每秒主动读屏播报，滑动操作保留触摸、键盘和读屏等价交互。

删除确认与错误提示使用同一套纸色弹窗和按压按钮，随明暗主题变化。删除前单独显示记录日期与时间，点击弹窗外空白、取消、系统返回及 Escape 均只会关闭弹窗，不会删除记录；短横屏、大字体及键盘遮挡时可滚动查看内容与操作。

随包字体均使用 SIL Open Font License 1.1，来源、使用范围及许可见 [assets/fonts/README.md](assets/fonts/README.md)。字体和声音随应用打包，无需联网加载。
